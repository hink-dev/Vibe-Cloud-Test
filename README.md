# Vibe Cloud Test - Android Projekt

Ein Testprojekt für Vibe Code Web (Mistral AI). Entwickelt komplett in der Cloud!

## 🚀 Schnellstart mit Vibe Code Web

1. **Gehe zu [chat.mistral.ai](https://chat.mistral.ai)**
2. **Wähle "Vibe Code Web"** oder sage: "Ich will Android-Code schreiben"
3. **Verbinde dein GitHub-Konto** (falls noch nicht geschehen)
4. **Öffne dieses Repository** und lass Vibe Code den Code bearbeiten!

## 📱 Beispielbefehle für Vibe Code

- "Füge einen neuen Button hinzu, der 'Test' anzeigt"
- "Ändere die Hintergrundfarbe der Activity zu Blau"
- "Führe ./gradlew build aus und gib mir den APK-Download-Link"
- "Erstelle eine neue Activity namens SecondActivity"

## 📁 Projektstruktur

```
Vibe-Cloud-Test/
├── app/
│   ├── build.gradle          # App-spezifische Konfiguration
│   ├── src/
│   │   ├── main/
│   │   │   ├── java/com/example/vibecloudtest/
│   │   │   │   └── MainActivity.kt  # Haupt-Aktivität
│   │   │   └── res/
│   │   │       └── layout/
│   │   │           └── activity_main.xml  # UI-Layout
│   │   └── AndroidManifest.xml  # App-Manifest
├── build.gradle              # Projekt-Level Konfiguration
└── settings.gradle           # Projekt-Einstellungen
```

## 🔧 Voraussetzungen

- Android Studio (optional, nur zum lokalen Testen)
- GitHub-Konto (für Cloud-Entwicklung)
- Mistral-Account (für Vibe Code Web)

## 💡 Tipps

- Nutze **Sprachbefehle** in Vibe Code Web für schnelle Änderungen!
- Die App kann **automatisch APKs bauen** (mit `./gradlew assembleDebug`).
- Für **Deploy auf dein Handy**: Lade die APK herunter und installiere sie manuell.
